# 回放页面使用说明（web/index.html）

在仓库根目录执行 `python3 -m http.server`，浏览器访问
`http://127.0.0.1:8000/web/index.html`。纯原生 ES module，无构建步骤、
不加载任何外部资源。

## 载入脚本

- 下拉框选择 `samples/scripts` 下的 13 个样例之一，点「加载样例」；
  页面加载后默认自动回放第一个样例。
- 或点「本地脚本」选择文件，或把 `.script` 文件拖到页面任意位置。

## 回放控制

- 「单步」执行下一条语句；「上一步」回退一条（内部为重置后重放到
  目标步，结果确定一致）；「重置」回到第 0 步。
- 「播放/暂停」连续回放，「每拍步数」控制速度；拖到滑块或点击曲线
  可跳到任意步。
- 中部状态区显示当前步号、语句原文与本步事件（`+创建`、`-释放`、
  `!错误码`）。

## 时间轴曲线

- 横轴为步号，纵轴为存活对象数；按「类别」分色绘制，类别 = 对象名
  去掉尾部数字（如 `t001→t`、`k1→k`、`hub→hub`）。
- 红色虚线标记环被回收的步（即产生释放事件的 `collect`），线顶端
  三角内的数字是该步回收的环数；曲线下方汇总「本次回放共释放 N 个
  环」，并逐条列出每次 collect 回收的环数与对象名单，点击可跳到该步。
- 环数口径：每次 `collect` 回收的对象集 D 按 D 内部边做弱连通分量
  划分，每个分量恰含至少一个环，分量数即该步回收的环数。
- 曲线与计数全部来自页面内嵌引擎（web/engine.js）对脚本的确定性
  回放，与命令行 `main.py` 的轨迹逐步一致（tests/js_replay_check.mjs
  逐样例校验）。

## 对象明细

底部表格列出当前步每个存活对象的 `ext`、`int`、`rc` 与出边（目标名
按字典序，重边标 `×条数`）；超过 200 行时只列前 200 行并提示总数。
